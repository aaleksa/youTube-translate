# YouTube Translator - Застосунок для роботи з текстами YouTube видео

Сучасний веб-застосунок для перегляду YouTube відео та роботи з їхніми субтитрами/трансляціями.

## 🚀 Можливості

- **Перегляд відео**: Вбудований плеєр YouTube прямо на сторінці
- **Завантаження трансляцій**: Автоматичне завантаження субтитрів/трансляцій відео
- **Пошук у тексті**: Швидкий пошук по транслюванному тексту
- **Копіювання тексту**: Копіювання всього тексту в буфер обміну
- **Завантаження файлу**: Збереження трансляції як текстовий файл
- **Статистика**: Виведення кількості слів, символів, рядків
- **Виділення тексту**: Можливість виділяти та переглядати вибраний текст

## 📋 Вимоги

- Node.js 18+
- npm або yarn

## 🔧 Встановлення

1. Клонуйте репозиторій:
```bash
cd yoytube-translaty
```

2. Встановіть залежності:
```bash
npm install
```

## 🎯 Запуск застосунку

Запустіть сервер розробки:
```bash
npm run dev
```

Застосунок буде доступний за адресою: `http://localhost:3000`

## 📝 Як користуватися

1. Вставте посилання на YouTube відео у поле введення
2. Натисніть кнопку "Get Transcript"
3. Очікуйте завантаження трансляції
4. Переглядайте відео та займайтесь текстом:
   - Вищуйте текст за допомогою поля пошуку
   - Копіюйте весь текст або вибрану частину
   - Завантажуйте текст як файл
   - Переглядайте статистику (слова, символи, рядки)

## 🔗 Підтримуванні формати посилань

- `https://youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- `https://youtube.com/embed/VIDEO_ID`

## 🛠️ Стек технологій

- **Next.js 16+**: React фреймворк для веб-додатків
- **TypeScript**: Типізована мова програмування
- **Tailwind CSS**: Утиліти CSS для стилізації
- **React**: JavaScript бібліотека для UI

## 🐛 Вирішення проблем

### "Could not fetch transcript for this video"
- Відео може не мати доступних субтитрів
- Спробуйте ввімкнути субтитри на YouTube сторінці відео
- Переконайтеся, що посилання правильне

### Застосунок не запускається
```bash
# Очистіть кеш
rm -rf .next node_modules
npm install
npm run dev
```
